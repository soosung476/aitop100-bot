# 리허설 절차 (10/28~29 예정)

목표: 대회 당일과 같은 순서를 시간을 재며 한 번 끝까지 해 본다.
(문제 읽기 → 자료 정리 → 지시문·도구 바꾸기 → 운영진 액션 서버 연결 → 시험 → 배포 → 카톡 확인 → 디브리프 → 제출)

- 「운영진 액션 서버」 역할은 가짜 서버(`examples/action_server/mock_server.py`)가 맡는다. 상품 조회, 회원 등급, 주문 등록·취소 API가 있다.
- 문제는 `~/aitop100-practice/문제5_모의예선/문제.md`이다. 자료는 문제 1~4 폴더를 쓰고, 정답 폴더는 보지 않는다. 제출 형식만 실제 대회에 맞춰 「링크」 대신 **카카오톡 봇 + App ID + 디브리프**로 바꾼다.

## 0. 준비 (시작 전 10분, Claude가 한다)

```bash
cd ~/aitop100-bot
git switch -c rehearsal-MMDD            # main은 그대로 두고 리허설용 브랜치에서 한다
cp prompts/템플릿.md prompts/system.md   # 지시문을 빈 틀로 (당일과 같은 출발점)
git rm -q data/*                          # 연습 문제 4번 자료를 뺀다 (main에는 남아 있다)
./scripts/rehearsal.sh on                 # 가짜 액션 서버 켜기 + 봇을 그 서버에 연결
./deploy.sh                               # 서버에 올리기
```
- 카카오톡 「탑톡」 채널(http://pf.kakao.com/_hJzWX/chat)에서 아무 말이나 보내 답이 오는지 확인한다.
- 자료 도구 상자 확인: `~/aitop100-tools/시험/시험.sh` → 마지막 줄이 「전부 통과」인지 본다. (설명은 `~/aitop100-tools/README.md`)
- 「운영진이 준 API 문서」는 `examples/action_server/data/액션서버_API.md`이다. 당일에는 문제 페이지에서 받는다. 리허설 중에 `data/`로 복사해서 쓴다.

## 1. 진행 (5시간, 가능하면 10:00~15:00)

| 시간 | 할 일 | 산출물 |
|---|---|---|
| 09:00~09:20 | 입장 흉내: 환경 인증 사진 각도 연습 (모니터 + 주변 1m, 사람·손 안 나오게) | |
| 10:00~10:50 | 자료 받기 → `~/aitop100-tools/자료변환.sh <받은 폴더>` → `_요약.md`(숨은 글자, AI에게 하는 말)부터 읽기 → 인터뷰 분석, 문제 정의 | 문제 정의서 |
| 10:50~11:50 | 자료 정제 → `data/`에 넣기 (문서는 .md, 표는 .csv) | 정제된 자료 |
| 11:50~13:00 | `prompts/system.md` 채우기, API 문서를 `data/`에 넣기, 필요하면 `tools.py`에 도구 추가 | 에이전트 v1 |
| 13:00~14:00 | 시험: `chat_test.py` → `simulate.py`(가짜 서버, 고객 카드·공격 카드) → 고치기 | v2, 시험 결과 |
| 14:00~14:30 | 최종 `./deploy.sh` → 카톡에서 직접 대화 → `git commit` + `git tag` | |
| 14:30~14:45 | 디브리프 작성 (`docs/디브리프_초안.md` 채우기) → 「제출」 | |
| 14:45~15:00 | 여유 | |

- 실제 대회에서는 14:30~14:40까지 제출이 목표다. **제출한 뒤에는 아무것도 바꾸지 않는다.** 리허설에서도 지켜 본다.
- 시험 명령어는 `README.md`의 「시험 명령어」를 쓴다. 리허설 모드에서는 `.env`에 액션 서버 설정이 들어 있어서 `--expected examples/action_server/정답.json`만 바꾸면 된다.
  - 가짜 서버에는 자동 시험을 여러 번 돌려도 된다. **당일 운영진 서버에는 돌리지 않는다.**
- 지시문·자료를 다 채운 뒤 동시 접속 시험(`scripts/loadtest.py`, README 「가짜 액션 서버로 연습」)도 한 번 돌린다. 자료가 커지면 느려지므로 48명 줄의 「가장 늦음」을 적어 둔다. (10/25 연습 자료 기준: 48명 모두 답함, 가장 늦음 64초, 429 0번)
