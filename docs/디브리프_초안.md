# 디브리프 초안 (AI_TOP_100 [2026] 예선)

> 제출 항목: 제작한 AI 에이전트의 강점과 구현 방식
> `[ ]`는 제출 직전에 최종 시험 숫자로 채운다.

## 한 줄 요약
교동마을 산지직송의 카카오톡 고객 상담 에이전트입니다. 마을 관계자 인터뷰로 모은 규정과 운영 지식을 근거로 답하고, 액션 API로 주문·배송·결제를 직접 조회하고 환불·변경·이관까지 접수합니다.

## 강점
1. **근거 기반 응대**: 금액, 날짜, 상태는 액션 API 조회값으로만 말합니다. 전액환불 금액은 주문 결제액으로, 기한은 영업일 달력 도구로 계산합니다. 규정 원문 [ ]종과 관계자 인터뷰 지식을 지식 베이스로 넣었습니다.
2. **실제 처리**: 하자 신고면 배송 → 로트 → 조사 기록 → 같은 로트 신고 이력까지 확인하고, 고객 선택을 받은 뒤 환불이나 재배송을 접수하며, 필요하면 담당자 이관까지 별도로 접수합니다. 접수 API는 정책을 검사하지 않으므로 호출 전에 규정을 확인하도록 설계했습니다.
3. **심사 기준에 맞춘 응답**: 답변은 말풍선 하나, 200자 안팎으로 제한하고, 필요한 정보를 한 번에 물어 주고받는 횟수를 줄였습니다. SimpleText만 보내고 500자 이하를 코드로 보장합니다.
4. **속도**: 조회를 한 번에 병렬로 호출하고, LLM 생각 수준을 조정했습니다. 호출이 늦어지면 같은 요청을 하나 더 보내 먼저 온 답을 쓰고, 오류가 나면 예비 모델로 넘어갑니다. 50초 안에 끝나지 않으면 안내 문구로 답해 60초 무응답을 막습니다.
5. **멀티모달**: 고객 사진은 LLM 비전으로 내용을 글로 옮기고, 음성은 서버의 Whisper로 받아써서(제주 사투리 포함) 같은 흐름으로 처리합니다. 파일은 카카오 CDN 주소만 받습니다.
6. **보안**: 관리자 사칭, 가짜 [SYSTEM], 자료 속 지시를 따르지 않습니다. 지시문 유출 자동 차단, 액션 서버 밖 호출 차단, 데이터 초기화 경로 차단을 코드로 넣었고, 타인 정보와 저장 정보는 먼저 말하지 않습니다.

## 구현 방식
- **구성**: 카카오톡 채널 → 웹훅(FastAPI, 가비아 클라우드) → 에이전트(Hive GLM 5.3 Flash, 예비 DeepSeek V4.1 Flash, 도구 호출 반복) → 액션 API → 카카오 콜백 API
- **케이스 처리**: 대화 첫머리의 case metadata에서 케이스 ID를 찾아 API 헤더에 넣고, 인입 일시를 기준일로 판단하며, 케이스가 바뀌면 대화 기억을 새로 시작합니다.
- **지식 베이스**: 판매·환불 규정, 조합 규정집, 택배사 계약서, 개인정보 처리방침, 증빙 발행 기준, 정기배송 약관, 조합원 약관, 산지 기상 기준, 영업일 달력 등 [ ]종과 유형별 처리 절차
- **도구**: 액션 API 호출, 계산, 날짜 도구(영업일 기한, 컷오프 역산, 다음 출고일)

## 구현 과정
1. 문제와 공개 TC를 읽고 평가 메시지 형식, 케이스 헤더, 60초·500자 제약을 먼저 봇에 반영했습니다.
2. 관계자 [ ]명을 인터뷰하며 문서 원본과 현장 지식을 모아 지식 베이스에 넣었습니다.
3. 공개 TC 15개를 가상 고객과 채점 LLM으로 자동 시험했습니다. 기대 대응 항목 단위로 채점해 틀린 원인을 일반 규칙으로 고쳤습니다.
   - 예: 환불 금액을 현재가로 계산하는 실수 → 주문 결제액 규칙
   - 예: 주문번호를 묻지 않고 계정 주문을 뒤지는 문제 → 대상 주문 확인 규칙
4. 두 모델과 생각 수준을 비교해 정확도와 속도가 가장 좋은 조합을 골랐습니다. p95가 33.9초에서 [ ]초로 줄었습니다.
