## 막혔을 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 카톡 답이 없음 | `ssh -i ~/.ssh/aitop100_gabia ubuntu@1.201.111.145 'journalctl -u aitop100-bot -f'` |
| 로그에 `MESSAGE_CREATE`가 없음 | 카카오 → 서버 구간. 웹훅 주소, nginx 확인. `커스텀 헤더 불일치`가 찍히면 헤더 값 문제 |
| `MESSAGE_CREATE` 뒤로 아무것도 없음 | LLM이나 도구가 아직 처리 중(최대 4분). `HTTP Request` 줄의 429 확인, Hermes를 껐는지 확인 |
| 카톡에 「지금 답변이 어려워요」가 옴 | 에이전트 오류. 로그의 `에이전트 실패` 줄 확인. 이때도 `ANSWER`는 찍힌다 |
| `ANSWER`는 있는데 카톡에 안 옴 | 콜백 오류. `callback 실패` 줄과 봇 토큰 확인 |
