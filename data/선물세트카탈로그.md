# 선물세트 카탈로그 (포장·카드 옵션)
교동마을 산지직송
선물세트 카탈로그
명절·기념일 선물 구성과 포장 옵션
1. 선물세트 구성
명절 선물은 감귤과 만감류가 주력입니다. 아래가 이 카탈로그에 실린 세트 전부입니다.
| 세트 | 구성 | 주로 나가는 때 |
| 명절 감귤 세트 | 하우스 감귤 당도선별 5kg 1박스 | 명절 전후 (8~9월) |
| 감귤 대용량 세트 | 노지 감귤 10kg 1박스 | 11~2월 |
| 만감류 세트 | 한라봉·천혜향 3kg 또는 5kg 1박스 | 설 전후 (12~3월) |
| 여름 과일 세트 | 통수박 1통 · 애플망고 2kg · 멜론 2과 중에서 고르실 수 있습니다 | 6~8월 |
| 저장 채소 세트 | 감자·고구마 5kg (한 가지 또는 반반) | 10~12월 |
| 수산 냉동 세트 | 갈치·옥돔 손질 냉동 (갯마을 조합 위탁 공급) | 연중 |
· 같은 세트라도 그해 수확 상황과 시즌에 따라 규격·구성이 달라질 수 있습니다. 판매 시기의 구성과 가격은 주문 화면에서 확인해 주세요. 아직 판매하지 않는 시즌 상품은 판매가 시작될 때 가격을 안내드립니다.
· 위 목록에 없는 품목으로 세트를 꾸며 드리지는 않습니다.
· 아래 §2~§6의 포장·카드 옵션은 품목과 무관하게 모든 선물세트에 같게 적용됩니다.
(빈 표)
2. 함께 신청하실 수 있는 것
주문서의 [선물 옵션]에서 고르실 수 있습니다.
| 옵션 | 내용 | 비용 |
| 리본 포장 | 박스 겉면에 리본과 띠지를 둘러 드립니다 | 무료 |
| 보자기 포장 | 박스를 전통 보자기로 감싸 드립니다 — 쪽빛(남색)·다홍(붉은색) 두 색 중에서 고르실 수 있고, 안 고르시면 쪽빛으로 보냅니다 | 무료 |
| 손글씨 카드 | 카드 1장에 문구를 대필해 넣어 드립니다 (§3) | 무료 |
| 가격표 제거 | 거래명세서와 가격이 적힌 인쇄물을 넣지 않습니다 | 무료 |
| 수령인 직접 발송 | 주문자 주소가 아닌 받으실 분 주소로 바로 보냅니다 | 무료 |
| 혼합 구성 | §1의 세트 안에서 품목 2~3종을 섞어 담아 드립니다 (여름 과일 세트·저장 채소 세트) | 구성가 |
· 가격표 제거를 신청하시면 거래명세서는 박스에 넣지 않고 주문자에게 따로 보내 드립니다.
· 받으실 분의 성명·주소·연락처는 주문서에 입력하신 내용만 사용합니다. 상담 창구에서 저장된 주소·연락처를 읽어 드릴 수는 없습니다. 주문자께서 정보를 먼저 말씀해 주시면 주문서와 일치하는지 대조해 드립니다.
3. 카드 문구 규칙
· 길이 — 한글 30자 이내(공백 포함), 줄바꿈 2회까지
· 접수 — 주문서 요청사항에 직접 입력해 주세요. 전화·채팅으로 말씀해 주신 문구는 옮겨 적지 않습니다(오기 방지)
· 대필 — 청년회 담당자가 손으로 씁니다. 필체·서식·색상은 지정하실 수 없습니다
· 변경 — 출고 전까지 가능합니다. 출고 후에는 바꿀 수 없습니다
· 다음은 카드에 적어 드릴 수 없습니다
1. 전화번호·계좌번호·주소 등 개인정보
2. 특정인을 비방하거나 위협하는 표현
3. 상품·조합과 무관한 광고·홍보 문구
4. 질병 치료·예방 등 의약적 효능 표현
쪽빛·다홍 보자기와 리본, 손글씨 카드 포장 예시
4. 신청하실 수 없는 것과 그 이유
| 신청하실 수 없는 것 | 이유 |
| 껍질·과피 각인 (글자 새김·칼집·레이저) | 껍질에 상처가 나면 그 자리로 수분이 빠지고 미생물이 들어가, 배송 도중 갈변과 부패가 빠르게 진행됩니다. 받으실 때의 상품성을 보장할 수 없습니다 |
| 과육 안에 물건 넣기 (반지 케이스·쪽지 등) | 식품 위생상 허용되지 않습니다. 속을 열면 그 자리에서 부패가 시작됩니다 |
| 특정 날짜·시각 지정 배송 | 산지에서 수확·선별한 당일 출고하는 산지직송이라 출고일을 앞뒤로 고정할 수 없습니다. 대신 출고 시 알림을 보내 드립니다 |
| 박스 외관 커스텀 (인쇄·색상·로고 변경) | 정해진 포장재만 사용하며, 박스를 별도로 인쇄하거나 제작하지 않습니다 |
| 문양·도안 지정 포장 (개별 제작 포장지·인쇄 보자기) | 포장재를 건별로 만들지 않습니다. 보자기는 §2의 두 색 중에서 고르실 수 있습니다 |
| 받으실 분의 주소·연락처 제공 | 저장된 정보를 읽어 드릴 수는 없습니다. 주문자께서 먼저 말씀하신 정보의 대조와 배송 상태 안내는 가능합니다 |
추가 비용을 내셔도 위 서비스는 제공하지 않습니다. 상품의 위생·품질, 정해진 포장·배송 방식과 개인정보 보호 기준에 따라 운영합니다.
5. 대신 이렇게 해 드립니다
· 전하고 싶은 말은 손글씨 카드에 담아 드립니다(§3). 각인 대신 이 카드가 그 자리를 맡습니다.
· 보자기 + 리본을 함께 신청하시면 겉모습이 선물답게 됩니다.
· 반지 케이스처럼 직접 준비하신 물건은 고객님께서 따로 전달해 주세요. 조합이 상품에 넣어 드리지는 않습니다.
· 주문 전에 받으실 분이 수령 가능한지 확인해 주세요. 출고 알림을 받으시면 받으실 분께도 알려 주세요. 도착 날짜와 시각은 지정할 수 없습니다.
6. 목록에 없는 요청
카탈로그에 안내된 옵션 외에 별도 가공이나 맞춤 제작은 받지 않습니다. 상담이나 제작 담당자를 통해서도 추가할 수 없습니다. 손글씨 카드와 보자기·리본 포장을 이용해 주세요.
