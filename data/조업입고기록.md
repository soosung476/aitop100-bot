## 시트 '2. 기록 확인 기준'
| 2. 기록 확인 기준 |
|  | 규칙 |
| ① | 조업과 운송은 다르다. 조업 중단은 어획·입고 사정이고, 택배가 인수했는지와 배편이 운항하는지는 「시원배송 결항·집하 기록」에서 따로 확인한다 |
| ② | 조업 중단이 곧 수산물 전량 품절은 아니다. 냉동 재고가 남은 어종은 정상 판매할 수 있다 |
| ③ | 재개일은 정상화일이 아니다. 조업이 부분 재개돼도 소량 입고분은 밀린 예약 순으로 발송할 수 있다. 특보 해제만 보고 즉시 정상 발송을 약속하지 아니한다 |
| ④ | 기록에 없는 상태를 정상으로 채우지 않는다. 정상은 확인 결과이고, —가 쓰인 경우에는 그 시점에 관측·확정된 사실이 없다는 뜻이다 |
| ⑤ | 같은 품목의 품절이라도 날짜별 원인을 구별한다. 기상특보에 따른 조업 중단과 비성어기 소량 조업·재고 소진을 서로 바꾸어 설명하지 아니한다 |
| ⑥ | 기상 발표는 해당 날짜의 배경으로 인용한다. 뒤 날짜의 조업·입고 결과를 앞 날짜에 소급해 덮어쓰지 않는다 |
