# 산지 픽업 안내
1. 요건
| 요건 | 값 |
| 사전 예약 | 필수. 예약 없는 현장 방문 수령 불가 |
| 예약 마감 | 수령 희망일 1영업일 전 |
| 지정 장소 | 조합이 지정한 집하장 1곳 — 밭·하우스 현장 수령 불가. 실주소는 예약 확정 시 안내 |
| 지정 시간 | 영업일(월~금) 오전 중 1개 시간대 |
| 본인확인 | 주문자 본인 · 계정 명의 (§2) |
| 결제 | 온라인몰에서 결제한 주문에 한한다 — 현장 결제·현장 주문은 받지 않는다 |
| 문의·예약 접수 | 조합 온라인 상담 창구로 문의하면 담당 창구로 안내한다 |
집하·상차 시간대에는 픽업을 운영하지 않는다 — 동일 공간에서 택배 집하가 진행되어 물량 혼재가 발생하기 때문이다. 운영 시간 제한은 이러한 사유에 따른 것이며, 고객 안내 시 해당 사유를 함께 설명한다.
2. 본인확인
|  | 규약 |
| 원칙 | 계정 귀속이 확인된 주문자 본인 (「조합 규정집」 제8조) |
| 확인 | 주문번호 + 계정 명의 |
| 대리 수령 | 주문자가 예약 단계에서 사전 지정한 경우에만 |
| 금지 | 이름·전화번호 등의 정보를 알고 있다는 사실만으로 물품 인도 |
| 금지 | 예약자·수령인의 연락처·주소를 문서·안내에 적기 (「제3자 정보 보호 조항(공급자·직원·수령인)」) |
3. 냉장 유지 책임
| 구간 | 책임 |
| 예약 확정 ~ 인수 전 | 조합 — 지정 보관 상태 유지 |
| 인수 시점 이후 | 고객 — 이동 중 온도 관리 포함 |
인수 시점이 책임 경계다. 픽업에는 배송 구간과 이에 따른 콜드체인 구간이 없다 — 차량에 실은 뒤의 품온 상승은 하자 사유로 접수되지 않는다. 예약 확정 시 보관·이동 안내를 함께 주며, 보관 조건은 「박스 동봉 안내문(보관법·CS 연락처·접수 기한)」 박스 동봉 안내문과 같은 값을 쓴다.
4. 배송비 · 기한 · 미수령
|  | 값 |
| 배송비 | 미부과 — 배송 구간이 발생하지 않는다 |
| 하자 접수 기한 | 픽업일이 수령일이다 → 「판매·환불 규정」 제20조 기한이 그날부터 |
| 청약철회 | 소매 규정을 따른다 (「판매·환불 규정」 제11조③) |
| 현장 확인 | 인수 전 개봉·확인 가능. 확인 후 인수 거절은 주문 취소로 처리 |
| 지정 시간 내 미수령 | 당일 1회 재예약 |
| 재예약분도 미수령 | 신선식품 품질 유지가 어려워 주문 취소·환불 |
| 미수령 사유가 조합 측 | 배송 전환(배송비 미부과) 또는 전액환불 |
픽업은 현장에서 상품을 확인한 후 인수를 거절할 수 있다. 현장에서 인수를 거절하는 경우 배송·반송 비용은 발생하지 않는다.
5. 픽업 이용 안내
"제주 현지에서 직접 수령하실 수 있습니다. 다만 사전 예약제로만 운영하고, 조합이 지정한 집하장에서 지정 시간에만 수령하실 수 있습니다. 집하·상차 시간에는 물량 혼재로 인해 픽업을 운영하지 않습니다. 예약해 주시면 장소와 시간을 안내드리겠습니다. 수령하실 때는 주문번호와 주문자 본인확인이 필요하며, 대리 수령을 희망하시는 경우 예약 단계에서 사전에 지정해 주셔야 합니다. 배송비는 부과하지 않습니다. 인수 이후의 온도 관리는 고객님께서 담당하셔야 하므로, 여름철에는 차량에 장시간 보관하지 마시고 바로 냉장 보관해 주십시오. 현장에서 상품 상태를 확인한 후 인수하실 수 있습니다."
