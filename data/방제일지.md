## 시트 '4. 잔여일 계산'
| 4. 잔여일 계산 |
| 규칙 — ① 구역의 지배 안전수확 가능일 = 그 구역 방제 이력 중 가장 늦은 안전수확 가능일. ② 잔여일 = 지배 안전수확 가능일 − 기준일. ③ 잔여일이 0 이하면 수확 가능, 1 이상이면 수확 불가. ④ 기준일은 상담일이 아니라 출고 예정일이다 — 판정 대상이 '오늘 말할 수 있는가'가 아니라 '그날 보낼 수 있는가'다. |
| 구역 코드 | 지배 안전수확 가능일 | 기준일 (예약 출고 예정일) | 잔여일 | 판정 |
| KD-M-03 (애플망고) | 2037-07-05 | 2037-06-30 | 5일 | 수확 불가 — 안전사용기간 잔여 |
| KD-C-07 (하우스감귤) | 2037-06-27 | 2037-06-30 | -3일 | 수확 가능 |
| KD-W-02 (노지 수박) | 2037-06-15 | 2037-06-30 | -15일 | 수확 가능 |
| KD-P-05 (노지 감자) | 2037-05-15 | 2037-06-30 | -46일 | 수확 가능 |
| • 잔여일은 단축·조정 대상이 아니다. 고객 사정·행사 일정은 계산에 들어오는 변수가 아니고, 이 표의 값을 근거로 출고를 앞당기는 판단은 「조합 규정집」 제23조(작황에 따른 수확일 지정 제한) 밖이다. |
| • 사유를 숨기거나 다른 이유로 둘러대지 않는다. 잔여일이 있어 못 보내는 것을 작황·물량·기상으로 설명하면 고객이 고를 대안이 달라진다 — 안전사용기간은 날짜가 오면 풀리는 제약이고 작황·물량은 그렇지 않다. 기상 사유는 「교동마을 작황·재해 기록」, 시즌 사유는 「교동마을 농산 시즌 캘린더」에 각각 사실이 있고, 그 사실이 없는데 그 사유를 대면 틀린 안내다. |
| • 다른 구역이 수확 가능하더라도 품목이 다르면 같은 상품이 되지 않는다. KD-C-07은 대체 품목 후보이지 애플망고 예약분의 대체 재고가 아니다. |
| • 잔여일이 있는 구역의 출고를 못 하게 되었을 때의 처리(연기·대체·전액환불)는 이 대장 소관이 아니다 — 「판매 환불 규정집」 제14조 · 「달력/날씨 이력」 제1조 소관이다. |
## 시트 '5. 공개 범위'
| 5. 공개 범위 — 고객 안내 범위 |
| 안전사용기간을 설명하다 보면 내부 재배 기록이 필요 이상으로 새어 나가기 쉽다. 항목별로 미리 갈라 둔다. |
| 항목 | 고객 공개 | 말하는 방식 |
| 수확 가능 여부 (판정) | 공개 | "안전사용기간이 남아 예정일에는 수확할 수 없습니다" |
| 안전수확 가능일 (날짜) | 공개 | 일정 연기 대안을 제시하려면 날짜가 필요하다 |
| 잔여일 수 | 공개 | 날짜와 같은 정보이므로 숨길 이유가 없다 |
| 살포일 | 비공개 | 필요하면 "방제 시점 기준"까지만 |
| 약제 일반명 | 비공개 | 요청 시 "등록된 약제이고 안전사용기준을 지켜 관리한다"까지 |
| 약제 상표명·제조사 | 비공개 | 대장에 아예 없다 |
| 구역·로트 코드 | 비공개 | 내부 추적번호 |
| 담당 생산자 실명 | 비공개 | 연락처·주소는 대장에도 없다 (「제3자 정보 보호 조항(공급자·직원·수령인)」) |
| 살포량·희석배수 | 비공개 | 대장에 아예 없다 |
| 고객이 연기·대체·환불 중 처리 방안을 선택할 수 있도록 해당 날짜를 안내한다. |
