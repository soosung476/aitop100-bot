## 시트 '3. 기록 확인 기준'
| 3. 기록 확인 기준 |
|  | 규칙 |
| ① | 작황과 물류는 별개의 확인 대상이다. 하우스 작황 영향이 낮아도 배편이 막힐 수 있다. 배송 여부는 「시원배송 결항·집하 기록」, 갯마을 조업은 「갯마을 조업·입고 기록」의 해당 날짜 기록과 구분해서 읽는다 |
| ② | —는 그 시점에 관측·확정된 사실이 없다는 뜻이다. 피해 없음도 피해 발생도 아니다. 예보 단계의 미확정 상태를 뒤에 확인된 결과로 채워 읽지 않는다 |
| ③ | 영향 없음은 확인 결과 피해가 없다는 판정이다. —와 다른 값이다. 이 기록에 없는 날짜도 피해 없음으로 단정하지 아니한다 |
| ④ | 일지는 사후에 채워진다. 뒤 날짜에 확인한 결과를 예보 행에 소급해 덮어쓰지 않는다 |
| ⑤ | 품목 표기와 코드는 「품목별 SKU 카탈로그(1차 6종 + 수산물)」가 정본이다. 이 기록의 품목 열은 해당 날짜에 확인한 농산의 범위이며 판매 품목을 새로 정하지 아니한다 |
| ⑥ | 특보 해제가 곧 출고 정상화는 아니다. 숙도·수확 회복과 집하 재개를 따로 확인하며, 출고 재개 시점이 미확정이면 날짜를 만들어 약속하지 아니한다 |
| ⑦ | 기상이나 지체 기록의 존재만으로 하자·배상 사유를 확정하지 아니한다. 실제 작황·상품 상태와 적용 규정을 함께 확인한다 |
